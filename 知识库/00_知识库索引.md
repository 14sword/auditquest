# 知识库：六张卡片

这六份不是论文，是**做题时会去翻的东西**。每一份都对应游戏里的一个位置。

| 文件 | 对应位置 | 什么时候翻 |
|---|---|---|
| `01_销售与收款循环_红旗清单与程序.md` | 第 4、5 章；看板 05/07 节 | 想不起「这笔为什么可疑」「下一步调什么」 |
| `02_Benford首位检验_操作手册.md` | 看板 04 节 | 看到首位分布图，不确定阈值和适用条件 |
| `03_审计意见类型_判定对照表.md` | 成绩页 → 审计报告「意见卡」 | 想知道为什么自己那份报告是这个意见 |
| `04_SQL筛查规则库_十二条.md` | 看板 05 节的代码块 | 想自己照着规则跑一遍 |
| `05_审计术语速查_中英对照.md` | 全部 | 名词对不上、英文不确定 |
| `06_错题归因_常见混淆对照表.md` | 错题本、复核清单 | 答错了，想知道错在哪一类 |

## 三条使用建议

1. **先做题再看**。这些卡片是查漏用的，不是预习用的——没做过题，看哪一条都像懂了。
2. **只补那一对概念**。第 6 张表的写法是「你的直觉 / 实际规则 / 要分清的一对」，错题多半是两个概念粘在一起，切开就够，不用整章重刷。
3. **卡片是解释，不是依据**。真要引用，回到《题库与官方来源清单》的 S1—S13，那里有原文链接与可信度标注。

这六份已导入 IMA「学校相关任务」库，与《题库与官方来源清单》《题源汇编与命题映射》并列。在 IMA 里可以直接问「拆单怎么筛」「无法表示意见和保留意见差在哪」，它会引用这些卡片回答；卡片里每条结论都标了来源编号，可以顺着编号回原文核对。
