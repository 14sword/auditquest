# 审计意见类型：判定对照表

> 用途：《审计报告》「意见卡」的映射依据。来源 S4（中国注册会计师执业准则，CSA 1501/1502/1503/1504 系列）。
> 核心逻辑：意见类型不是按「公司好坏」分，是按**你能不能取得充分适当的证据**、以及**错报是否重大且广泛**分。

## 一、五种意见与触发条件

| 意见类型 | 触发条件 | 一句话 |
|---|---|---|
| 无保留意见 | 证据充分适当，不存在重大错报 | 可以签 |
| 带强调事项段的无保留意见 | 结论没问题，但有对使用者理解报表至关重要的事项 | 可以签，另起一段说清楚 |
| 保留意见 | 错报重大但不广泛；或范围受限重大但不广泛 | 大部分能签，局部除外 |
| 否定意见 | 取得充分证据，确认错报重大且广泛 | 报表整体不能反映真实情况 |
| 无法表示意见 | 无法取得充分适当的证据，且可能影响重大而广泛 | 不知道，所以不说 |

「重大」看金额是否影响使用者决策；「广泛」看是否波及多个科目、多个项目，或占报表很大比重。

## 二、两条判定轴

```
                错报/范围受限是否「广泛」
                     否            是
证据是否 充分 ┬ 否  保留意见      无法表示意见
（能否取得）  └ 是  保留意见      否定意见
```

- **拿不到证据**（范围受限）→ 保留 / 无法表示；
- **拿得到证据但确认有错**（存在错报）→ 保留 / 否定。
- 两者都不重大 → 无保留（必要时加强调事项段）。

## 三、什么算「强调事项段」

强调事项段不改变意见类型，只做提示：

- 已披露的重大不确定性（如持续经营重大疑虑、重大诉讼结果待定）；
- 资产负债表日后发生的重大事项；
- 会计政策变更、重大重组。

写的时候三件事齐全：**是什么、为什么重要、影响哪个报表项目**。含糊其辞（如「存在一定不确定性」）等于没写。

## 四、本作为什么只映射四种

《账本有鬼》用总分判定意见，一维映射如下（见报告页 `verdictOf`）：

| 总分 | 意见 | 理由 |
|---|---|---|
| ≥85 | 无保留意见 | 六块都做到位，证据链闭合 |
| 70—84 | 带强调事项段的无保留意见 | 结论成立，但有 1—2 处需单独说明 |
| 55—69 | 保留意见 | 有局部范围受限，不能整份签 |
| <55 | 无法表示意见 | 底稿不成体系，无法形成结论 |

**没有「否定意见」是有意为之**：否定意见要求同时满足「证据充分」+「错报重大且广泛」+「管理层拒绝调整」三个条件。游戏里没有「管理层态度」这个变量——你答错只是你没做到位，不是客户坚持不改。把「答错」判成否定意见，等于把审计师的能力问题说成客户的错，逻辑上不成立。

这条边界写在这里，是为了说明：**游戏机制可以简化，但不能自相矛盾。**

## 五、写一段意见的模板

```
一、审计意见
我们审计了……财务报表，包括……
我们认为，上述财务报表在所有重大方面按照……的规定编制，
公允反映了……（无保留意见表述）。

二、形成审计意见的基础
我们按照中国注册会计师审计准则执行了审计工作……
我们获取的审计证据是充分、适当的，为发表审计意见提供了基础。

三、关键审计事项（上市实体适用）
（一）收入确认
   ——事项描述、应对程序、结论

四、强调事项（如适用）
我们提醒财务报表使用者关注……

五、其他信息 / 管理层和治理层责任 / 注册会计师责任
```

## 六、三个容易混的地方

1. **强调事项段 ≠ 其他事项段**。前者影响使用者理解报表，后者是法律或准则要求沟通但不在报表列报的事项。
2. **保留意见 ≠ 部分无保留**。保留的是「除……影响外」的那一段，要写清「除」的是什么。
3. **无法表示意见 ≠ 不发表意见**。无法表示本身就是一种意见，仍须出具报告、仍须说明未能取得什么证据。

## 七、自测三题（不给答案，用来自查）

1. 客户拒绝你监盘存货，存货占资产 45%。出什么意见？
2. 你确认收入被提前确认 120 万元，占收入 4.2%，客户已按你的意见调整。出什么意见？
3. 客户只让你审一个子公司，母公司不让你碰。出什么意见？

（提示：分别看「范围受限是否广泛」「是否还有未更正错报」「受限范围占报表比重」。）
