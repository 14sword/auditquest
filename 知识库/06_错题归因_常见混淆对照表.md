# 错题归因：常见混淆对照表

> 用途：《账本有鬼》答错之后看这一张。左边是你选错的方向，右边是你真正该分清的那一对概念。
> 用法：先看解析，再来这张表找「我错在哪一类」，然后只补那一条，不要整章重刷。

## 一、准则与体系

| 你的直觉 | 实际规则 | 要分清的一对 |
|---|---|---|
| 三类审计差不多，都是查账 | 主体、授权来源、报告对象全不同 | **谁在审**：审计机关（法定职权）/ 内部机构（本单位）/ 事务所（受托） |
| 底稿归档后发现问题可以补进去 | 报告日起 60 天内归档，归档后保存期内不得删改 | **归档前 vs 归档后**：归档前可整理，归档后只能另附说明 |
| 准则编号记不住就按内容猜 | 编号对应固定规范对象，猜必错 | **编号 = 管什么**：1101 总则、1211 风险评估、1301 证据、1131 底稿、1141 收入 |
| 重要性只在开始定一次 | 情况变化可以修订，修订要记录 | **计划时确定 vs 过程中修订** |

## 二、风险与重要性

| 你的直觉 | 实际规则 | 要分清的一对 |
|---|---|---|
| 重要性就是一个固定百分比 | 是职业判断，可用基准×比例作起点 | **计算公式 vs 判断结论**：公式只是起点 |
| 内控好就可以少做实质性程序 | 控制测试有效才能依赖，且不能完全替代 | **信赖控制 vs 不做实质程序** |
| 舞弊是管理层的事，审计只管报表 | 审计师对「发现舞弊导致的重大错报」有责任 | **防止舞弊（管理层）vs 发现重大错报（审计师）** |
| 收入确认舞弊风险要自己判断有没有 | 准则推定存在，不认定要记录理由 | **推定存在 vs 可以反驳** |
| 小公司不需要评估舞弊风险 | 所有审计都要，规模只影响程序 | **风险高低 vs 有没有风险** |

## 三、证据与程序

| 你的直觉 | 实际规则 | 要分清的一对 |
|---|---|---|
| 回函没盖章就是错报 | 证据力不足，不等于错报 | **证据不足 vs 存在错报**：前者做替代程序 |
| 监盘是替客户数存货 | 是现场观察 + 抽盘，责任在客户 | **观察 vs 代行** |
| 函证发出去就行 | 寄发与回收必须由审计人员控制 | **客户代发 vs 审计控制** |
| 抽样没查到问题就说明没问题 | 只说明样本没问题，且受误受风险影响 | **样本结论 vs 总体结论** |
| 分析程序只在计划阶段用 | 计划、实质、终结三阶段都可用 | **用作风险评估 vs 用作实质程序** |
| 证据越多越好 | 相关性和可靠性优先于数量 | **充分性（量）vs 适当性（质）** |

## 四、IT 与数据

| 你的直觉 | 实际规则 | 要分清的一对 |
|---|---|---|
| ITGC 和 ITAC 是一回事 | ITGC 管系统本身，ITAC 管业务规则 | **系统能不能信 vs 规则有没有生效** |
| 数据导出来就能用 | 先做完整性（行数、合计、号段）与准确性核对 | **拿到数据 vs 数据可用** |
| 全量筛查比抽样高级，抽样没用了 | 两者解决不同问题，抽样仍适用于单笔属性 | **找模式（全量）vs 推断总体（抽样）** |
| Benford 异常就是有舞弊 | 只是线索，不能单独成结论 | **不自然 vs 舞弊** |
| 数据量大就该抽样 | 全量跑成本低时，全量优于抽样 | **成本约束 vs 方法优劣** |

## 五、舞弊与操守

| 你的直觉 | 实际规则 | 要分清的一对 |
|---|---|---|
| 亲属在客户做财务经理，回避那个科目就行 | 影响的是整体判断，应报告并评估防范措施 | **回避局部 vs 评价整体独立性** |
| 只要不在报告上签字就没问题 | 实质独立性看的是判断是否受影响 | **形式独立 vs 实质独立** |
| 客户请吃饭、送点小礼物很常见 | 要看是否重大、是否影响判断，且需记录 | **社交礼节 vs 独立性威胁** |
| 按审计结果收费很合理 | 审计业务禁止或有收费 | **或有收费（禁）vs 固定收费（可）** |
| 管理层解释了就可以采信 | 解释本身不是充分适当的证据 | **询问（程序）vs 证据（结论）** |

## 六、综合卷（跨章串联）

| 你的直觉 | 实际规则 | 要分清的一对 |
|---|---|---|
| 六章是六个独立知识点 | 一个案子里六章是串起来的：风险→控制→程序→证据→结论→报告 | **知识点的顺序 vs 案子的顺序** |
| 先想结论，再找证据 | 先定风险与重要性，再定程序，最后才出结论 | **结论先行 vs 证据先行** |
| 查出异常就等于查出舞弊 | 异常是需要解释的事项，不是定性 | **异常 vs 错报 vs 舞弊**：三级递进 |

## 七、怎么用这张表

1. 错题解析看完，回来找「你的直觉」那一栏，看是不是这一类的错。
2. 只补「要分清的一对」，不要重刷整章。
3. 同一对概念错两次以上，去《题库与官方来源清单》找该章来源编号，读原文那一段。
4. 补完再回到《审计报告》看板，看那一条程序是不是排到了前面。

> 一句话：错题不是「记不住」，多半是「两个概念粘在一起了」。把它们切开，比分清对错更有用。
