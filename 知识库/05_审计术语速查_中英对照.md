# 审计术语速查（中英对照）

> 用途：答题时对不上名词、写解析时不确定英文，都查这张表。共 62 条，按章分组，与《账本有鬼》六卷对应。
> 只收本作会用到的词，不做词典式罗列。

## 一、准则与体系（第 1 章）

| 中文 | 英文 / 缩写 | 一句话 |
|---|---|---|
| 注册会计师审计 | statutory audit | 事务所受托，按执业准则出报告 |
| 国家审计 | government audit | 审计机关依法定职权实施 |
| 内部审计 | internal audit | 本单位机构实施，服务管理层与治理层 |
| 执业准则 | CSAs | 中注协发布的注册会计师执业准则体系 |
| 审计准则 | Auditing Standards | CSA 1101 起编号序列 |
| 质量管理 | quality management | CSA 1121，项目层面与事务所层面 |
| 审计工作底稿 | audit working papers | 记录程序、证据与结论，报告日起 60 天内归档 |
| 审计档案 | audit file | 归档后保存期内不得删除或废弃 |
| 业务约定书 | engagement letter | 明确范围、责任、收费方式 |
| 合理保证 | reasonable assurance | 高水平但非绝对保证 |

## 二、风险与重要性（第 2 章）

| 中文 | 英文 / 缩写 | 一句话 |
|---|---|---|
| 重要性 | materiality | 影响使用者决策的金额门槛 |
| 实际执行的重要性 | performance materiality | 低于整体重要性，为未发现错报留缓冲 |
| 重大错报风险 | risk of material misstatement (RMM) | 报表在审计前就存在重大错报的可能 |
| 固有风险 | inherent risk | 不考虑控制时的风险 |
| 控制风险 | control risk | 内控没能及时防止或发现的风险 |
| 检查风险 | detection risk | 审计程序没查出来的风险 |
| 风险评估程序 | risk assessment procedures | 询问、分析、观察、检查 |
| 舞弊三角 | fraud triangle | 压力、机会、借口 |
| 舞弊风险因素 | fraud risk factors | 指向舞弊可能性的迹象 |
| 管理凌驾 | management override | 管理层越过控制，永远列为风险 |
| 收入确认舞弊推定 | presumed fraud risk in revenue recognition | 默认存在，除非有理由反驳并记录 |

## 三、证据与程序（第 3 章）

| 中文 | 英文 / 缩写 | 一句话 |
|---|---|---|
| 审计证据 | audit evidence | 充分性（数量）+ 适当性（相关、可靠） |
| 函证 | confirmation | 直接向第三方取得书面回函 |
| 积极式函证 | positive confirmation | 要求对方必须回复 |
| 消极式函证 | negative confirmation | 不同意才回复，证据力弱 |
| 替代程序 | alternative procedures | 回函未取得时，查签收、期后回款等 |
| 监盘 | physical observation / count | 现场观察盘点，不是替客户盘 |
| 分析程序 | analytical procedures | 比率、趋势、结构对比找异常 |
| 细节测试 | test of details | 逐笔核对，实质性程序的一种 |
| 控制测试 | test of controls | 验证控制是否有效运行 |
| 实质性程序 | substantive procedures | 细节测试 + 实质性分析程序 |
| 审计抽样 | audit sampling | 推断总体，有误受/误拒风险 |
| 误受风险 | risk of incorrect acceptance | 抽样结论说没问题，实际有问题（更危险） |
| 误拒风险 | risk of incorrect rejection | 抽样说有问题，实际没问题（影响效率） |
| 截止性 | cut-off | 交易是否记在正确期间 |
| 函证控制 | confirmation control | 寄发与回收全程由审计人员控制 |

## 四、IT 与数据（第 4 章）

| 中文 | 英文 / 缩写 | 一句话 |
|---|---|---|
| IT 一般控制 | ITGC | 访问、变更、运行、备份，管「系统本身」 |
| IT 应用控制 | ITAC | 输入校验、审批流、接口对账，管「业务规则」 |
| 数据完整性 | data integrity | 取全了没有：行数、金额合计、号段核对 |
| 数据准确性 | data accuracy | 取对了没有：字段类型、精度、口径 |
| 全量筛查 | full-population testing | 不做抽样，规则跑全部记录 |
| 数据可视化 | data visualisation | 把分布与异常画出来，便于发现形态 |
| 首位数字检验 | first-digit (Benford) test | 看首位分布是否符合自然规律 |
| 重复值检测 | duplicate detection | 同号、同额、同日多维比对 |
| 断号检测 | gap detection | 连续号段缺失，指向账外记录 |
| 计算机辅助审计技术 | CAAT | 用工具处理全量数据的技术总称 |
| 审计数据分析 | audit data analytics (ADA) | 从数据中识别异常、模式与风险 |
| 数据口径 | data definition / scope | 期间、含税与否、合并范围 |

## 五、舞弊与操守（第 5 章）

| 中文 | 英文 / 缩写 | 一句话 |
|---|---|---|
| 职业怀疑 | professional scepticism | 不预设管理层诚实，也不预设其不诚实 |
| 独立性 | independence | 实质上与形式上都不受妨碍 |
| 密切关系 | familiarity threat | 太熟导致判断被影响 |
| 自身利益 | self-interest threat | 收费、业务依赖影响判断 |
| 或有收费 | contingent fee | 按审计结果收费，审计业务禁止 |
| 防范措施 | safeguard | 消除或降至可接受水平的手段 |
| 关键审计事项 | key audit matters (KAM) | 上市实体报告中必须沟通的重点 |
| 强调事项段 | emphasis of matter | 不改变意见，只做提示 |
| 其他事项段 | other matter paragraph | 与使用者理解审计相关但不属于 KAM 的事项 |
| 未更正错报 | uncorrected misstatement | 管理层拒绝调整的错报，汇总评估 |
| 管理建议书 | management letter | 内控缺陷的书面沟通 |

## 六、意见与报告（贯穿）

| 中文 | 英文 / 缩写 | 一句话 |
|---|---|---|
| 无保留意见 | unmodified / unqualified opinion | 可以签 |
| 保留意见 | qualified opinion | 除某事项影响外 |
| 否定意见 | adverse opinion | 报表整体失实 |
| 无法表示意见 | disclaimer of opinion | 拿不到证据，不做结论 |
| 广泛 | pervasive | 波及多个科目或占报表很大比重 |
| 审计报告日 | date of auditor's report | 报告签发日，也是归档 60 天的起算点 |
| 期后事项 | subsequent events | 资产负债表日后至报告日之间 |
| 持续经营 | going concern | 未来 12 个月能否持续 |
| 重大不确定性 | material uncertainty | 需在报告中单独提示的情形 |
