# 审计闯关 · AuditQuest

面向审计学专业学生的小型知识闯关网页：**三章、十二题**，含角色创建、章节地图、章节结算、错题本与通关证书。

**在线试玩**：https://wbapp-qruvgcr6v47qbzw8ydczc5.app.workbuddy.host/?sharecode=ZJ4W7WBS5C

## 特点

- **单文件**：`index.html` 内联全部 CSS 与 JavaScript，双击即开，断网可运行
- **零依赖**：无 CDN、无外部字体、无 fetch、无 API Key、无 Service Worker
- **三章知识线**：中国审计准则与流程 / CPA《审计》科目框架 / CISA 五域与 IT 审计
- **游戏化流程**：创建身份 → 章节地图 → 逐章答题 → 章节结算 → 总成绩报告 → 通关证书
- **即时解析**：每题给出解析、来源编号（S1–S7）与可信度
- **错题本**：答错自动收集，附正确答案与解析
- **可复现评分**：12 题等权，总分 = 正确数 ÷ 12 × 100；三档 入门 / 达标 / 熟练
- **本地存档**：`localStorage` 记录最高分、名字与身份
- **本地提示**：按题号匹配的规则文本，**不调用任何在线大模型**

## 运行

直接用浏览器打开 `index.html`。或：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```
