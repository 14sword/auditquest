# 账本有鬼 · AuditQuest

一个只考审计框架、不考会计分录的闯关网页；答完题按你的正确率出一份审计报告——报告里那 4,860 张发票能查出几笔，取决于你六章各自答得怎么样。

**在线**：https://wbapp-qruvgcr6v47qbzw8ydczc5.app.workbuddy.host/?sharecode=ZJ4W7WBS5C
**报告页**：同站点 `/dashboard.html?sharecode=ZJ4W7WBS5C`

## 特点

- **单文件**：`index.html` 与 `dashboard.html` 各自内联全部 CSS 与 JavaScript，双击即开，断网可运行
- **零依赖**：无 CDN、无外部字体、无 `fetch`、无 API Key、无 Service Worker；角色与场景插画全部是内联 SVG 路径
- **30 题**：五章各 5 题 + 综合卷 5 题，题干一律写成具体现场，逐题标来源编号（S1–S13）与可信度
- **游戏化流程**：创建身份 → 案卷墙 → 逐章答题 → 章节结算 → 总成绩 → 结案证书
- **报告跟着答卷走**：总分映射审计意见类型（无保留 / 带强调事项 / 保留 / 无法表示），六章正确率各自决定那一类异常查出几笔；没做过题默认看「演示样本」
- **本地提示**：按题号匹配的规则文本，**不调用任何在线大模型**

## 两个页面

| | `index.html` | `dashboard.html` |
|---|---|---|
| 回答 | 准则怎么编号、风险在哪评估、CISA 五域各占几分 | 拿到 4,860 张发票，怎么定位异常、怎么落到程序 |
| 形态 | 有状态的过程 | 有结论的报告（八节，带意见类型） |
| 数据 | 30 道题 | 构造的模拟发票集，7 条规则命中 37 笔 |

报告页支持直接带参数看指定成绩的样子：`dashboard.html?r=73&c=80,60,100,40,80,70`（`r` 总分、`c` 六章正确率、`n` 姓名）。

## 知识库

`知识库/` 下七份卡片，按「做题时会卡住的地方」组织：销售循环红旗清单、Benford 操作手册、审计意见判定对照、12 条 SQL 筛查规则、62 条术语中英对照、错题归因表、索引。
